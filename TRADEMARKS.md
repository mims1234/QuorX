# The QuorX name and logo

QuorX's code is open source under the [Apache License 2.0](LICENSE). The name **QuorX** and the QuorX logo are not
part of that licence. They tell people a copy is the official one, so this page says how to use them.

## Welcome, no need to ask

- Saying your project is **based on QuorX**, **a fork of QuorX** or **works with QuorX**.
- Writing, talking or making videos about QuorX, with the name and logo, as long as it's clear you're not the project.
- Sharing unchanged copies of an official release, under the name QuorX.
- Linking to the project with the logo, unchanged.

## Please don't

- Call a changed version **QuorX**, or a name that could be mistaken for it. Give your fork its own name and logo.
- Use the name or logo so it looks as if the QuorX project made, checked or recommends your product.
- Use the name or logo in a product name, an app store listing or a domain name.
- Change the logo, or mix it into your own.

## Official downloads

Official copies of QuorX come only from:

- the [Microsoft Store](https://apps.microsoft.com/detail/9NBK5DMLMTFF?mode=direct),
- [GitHub releases](https://github.com/mims1234/QuorX/releases) of this repository, with `SHA256SUMS.txt` and a signed
  build attestation ([how to check a download](SECURITY.md)),
- the website, [quorx.genxmims.org](https://quorx.genxmims.org).

Not sure whether something is fine? Open an issue and ask.
