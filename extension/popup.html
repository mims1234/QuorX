Connect this Chrome to QuorX once. In QuorX open ⚙ Settings → Chrome extension and copy the key.

The agent in that chat can then work in this tab, signed in as you. Sending, deleting, buying and account changes ask you first in QuorX. Nothing else in your Chrome is touched.

Given to . While the agent works in it, Chrome shows “QuorX started debugging this browser”; Cancel there also takes it back.

Tip: give the tab its own window, so you can watch it and the agent can see it.
